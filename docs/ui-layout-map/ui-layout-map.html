§1W1 主窗口 · 总览布局

三栏布局：R1 顶栏(56px) → C1 左栏文件区(280px) + R2 右栏参数面板，右栏下半为 R3 预览区 + 日志面板。所有区域共享同一 Electron BrowserWindow。

编号区域说明
W1-R1顶栏高 56；顺序：01 Logo → 02 品牌名 → 03 版本号（动态读 package.json） ← 右端：06 清空 → 05 选择文件夹 → 04 选择图片
W1-C1左栏文件区宽 280；01 拖拽区（虚线框，PNG/JPG/WEBP/BMP/TIFF）· 02 文件数标题 · 03 文件列表（点击切换预览；✕ 移除；虚拟化）
W1-R2右栏参数面板01 色数(3~12) · 02 模板(6 种) · 03 主题(深/浅) · 04 裁切(复选框) · 05 格式(JPG/PNG) · 06 生成色卡主按钮 · 07 预览画布（同渲染链路 + 350ms 防抖）
W1-R3日志面板01 日志文本区（等宽，info 灰 / err 红，自动滚动到底）

§2W1-R1 顶栏 · 6 项

顶栏横向排布，品牌在左、操作在右。v1.0.0 起版本号由主进程 IPC 动态读取 package.json，不再硬编码 HTML。

编号控件说明
W1-R1-01彩色胶片 Logo40×40px；源文件 build/huepick-logo.png（1024² 居中裁剪）；打包时 build/icon.ico（9 种尺寸 16~1024）嵌入 exe 作为窗口 + 任务栏图标
W1-R1-02品牌名「HuePick」粗体 16px；紧接 Logo 右侧，间距 10px
W1-R1-03版本号「v1.0.0」主进程 fs.readFileSync(package.json, 'utf8') → JSON.parse.version → ipcMain.handle('app-version') → preload.js window.huepick.getVersion() → renderer app.js DOMContentLoaded 异步写入 HTML span#ver；唯一来源 = package.json 的 version 字段，改一处自动全链路同步
W1-R1-04按钮「选择图片」dialog.showOpenDialog，多选，过滤器 image/*
W1-R1-05按钮「选择文件夹」dialog.showOpenDialog({ openDirectory })，递归收集目录下所有图片
W1-R1-06按钮「清空」ghost 样式（灰边透明底）；清空文件列表 + 重置预览空态 + 清空日志面板

§3W1-C1 左栏文件区

两个区域：顶部拖拽区（200px 高，虚线框）+ 下方文件列表（剩余空间）。窗口任何位置都可接受拖拽，不局限于拖拽区——document 级事件监听。

编号控件说明
W1-C1-01拖拽区（虚线框）高 200px；CSS border-style: dashed；dragover 事件 → 添加 .dragover 类（border-color/accent-color + 轻微缩放）；drop 事件 → 双路径合并（dataTransfer.files + webkitGetAsEntry 递归收集文件夹）→ Set 去重 → loadFiles() 入列表
W1-C1-02文件数标题动态文本「已加载 N 张」
W1-C1-03文件列表每项：缩略图（img src=file:// + ?t=Date.now() 绕缓存）+ 文件名 + ✕ 移除按钮；点击 → generatePreview(targetFile) → window.huepick.generateCard({ ...payload, sourcePath, preview:true }) → 主进程临时目录 + 返回 dataUrl → img.src 更新；当前选中项 CSS .selected 类（边框 2px accent-color）
W1-C1-04全局拖拽事件document.addEventListener('dragover', preventDefault) + document.addEventListener('drop', handleDrop)；#drop 拖拽区仅做视觉提示，不接收事件

§4W1-R2 右栏参数区

上半：参数面板（5 个参数横排）+ 生成按钮（左）+ 预览画布（右）；所有参数控件 change/input 事件挂 triggerPreviewDebounced，350ms 防抖调 generatePreview。

编号控件说明
W1-R2-01色数 下拉<select id="p-color">，option 3~12；change + input 事件 → triggerPreviewDebounced()（350ms 防抖）；映射到 CardOptions.numColors
W1-R2-02模板 下拉<select id="p-template">；6 种：landscape(1920×1080) / portrait(1080×1920) / square(1080×1080) / compact(1200×800) / thumb(800×450) / palette(1200×240)；值同时决定 TEMPLATE_SIZES 查表结果 + CardOptions.template → cardRenderer.ts 选择版式分支（横排/竖排/自动网格/palette 无图）
W1-R2-03主题 下拉<select id="p-theme">；dark → {r:24,g:24,b:26} / light → {r:245,g:245,b:247}；cardRenderer.ts 动态计算 inkColor/separatorColor/swatchBorderColor/textColorFor（基于背景亮度 0.299R+0.587G+0.114B 阈值 140）
W1-R2-04裁切 复选框<input type="checkbox" id="p-crop" checked>；默认开；cropBlackBars() → 扫描上下黑边像素比阈值 → 裁剪；关则跳过
W1-R2-05格式 下拉<select id="p-format">；JPG（canvas.toFile({format:'jpeg', quality:0.92})）/ PNG（canvas.toFile({format:'png'})）
W1-R2-06按钮「🚀 生成色卡」.btn-primary（accent 蓝背景 #2E8AB0）；generateAllCards() → 遍历 fileList → payload 含 sourcePath + readPayload() 全部参数 + preview=false → 主进程 ipcMain.handle('generate-card') → fs.readFileSync(package.json).version 注入 → generateCard(sourcePath, CardOptions) → canvas → fs.mkdirSync → canvas.toFile(outputPath, format) → 输出目录 = path.dirname(sourcePath)（预览模式 = app.getPath('temp') + '/HuePick-preview'）→ 文件名冲突自动编号：原名_色卡.jpg → (2)/(3)/… → 返回 { ok:true, outputPath, dataUrl, colors }
W1-R2-07预览画布<img id="preview">；preview 模式 payload.preview=true → 主进程 outputPath 落到 %TEMP%/HuePick-preview/ → canvas.toFile('jpg', 0.92) → 返回 dataUrl → img.src 赋值（覆盖而非 append）；img.addEventListener('load' → 显示 / error → 显示空态）；空态：居中图标 + 文字「选择图片后自动生成预览」

§5W1-R3 日志面板

右栏下半部分，生成按钮正下方。等宽字体，三档颜色区分 info/success/error。所有拖拽/预览/生成过程全记录。

编号控件说明
W1-R3-01日志文本区<pre id="log">；等宽字体（Cascadia Mono / Consolas）；log(text, level) 函数：innerHTML 追加 + 自动滚动到底；level=info（灰）/ success（绿）/ err（红）；记录所有链路：拖拽入文件 / 预览参数 / 主进程 IPC 返回 / 生成完成 / 错误堆栈
