§0编号规则

W1 整窗（BrowserWindow）
C1 / C2 两栏（左文件区 / 右参数预览）
C1-XX 左栏子区域（01~04）
C2-RY 右栏子区域（R1 参数 / R2 预览 / R3 日志）
SB 底部状态栏
chip 图中编号可点击 / 悬停查看说明
左栏（文件区） 右栏（参数预览） 底部状态栏

§1W1 整窗总览

v1.2.0 起取消独立顶栏，整体改为 body { flex-direction: column }，主 .layout 占满剩余空间，底部固定 28px 状态栏。

ID选择器尺寸/位置说明
C1.panel.leftgrid 第一列 320px左栏：品牌 + 拖拽 + 列表 + 清除按钮
C1-01.brand左栏顶部，padding 24px 16px品牌区：Logo 64×64 + 「拾色」26px / HuePick 13px，居中
C1-02.dropzonemargin 12px, padding 20px 14px拖拽区：单击=选图片（可多选），链接=选文件夹
C1-03.file-listflex:1 占满剩余文件列表：支持 Windows 选择逻辑
C1-04.clear-btn高 36px, margin 10px 12px 12px清除按钮：智能切换「清空列表」/「删除选中 (N)」
C2.panel.rightgrid 第二列 1fr右栏：参数 + 预览 + 日志
C2-R1.paramspadding 22px 26px参数面板：色数/模板/主题/裁切/格式 + 生成按钮
C2-R2.previewflex:1 占满剩余预览区：参数变化 350ms 防抖自动刷新
C2-R3.log高 100px日志面板：等宽字体，三档颜色（ok/err/info）
SB.statusbar高 28px, flex-shrink:0底栏：版本号 + 状态文字

§2C1 左栏详解

v1.2.0 把原顶栏的功能全部下沉到左栏，让左栏成为「文件管理 + 品牌展示」的完整单元。

ID选择器说明
C1-01a.brand .logoLogo 64×64px 圆角 14px，src=assets/logo.png（真实彩色胶片图标）
C1-01b.brand-text「拾色」26px 粗体字距 3px + HuePick 13px 浅灰字距 1px，垂直堆叠
C1-02#drop单击 → pickFiles()；#link-folder 单击 → pickFolder()（stopPropagation）
C1-03#file-listtabindex=0 接收键盘；每项含 ✕ 单删按钮（不冒泡到选中逻辑）
C1-04#btn-clear文本动态切换；列表为空时 disabled

§3C2 右栏详解

右栏是「参数 → 预览 → 日志」的垂直工作流。

ID选择器说明
C2-R1.params参数面板，grid 横向 wrap，gap 16px 28px；改任何参数 350ms 防抖触发预览
C2-R1a#btn-generate主按钮，linear-gradient(135deg, #4a9eff, #7b5cff)
C2-R2#preview预览区，空时显示 🎯 占位；预览图加 ?t=Date.now() 绕开缓存
C2-R3#log日志区，等宽字体 12px，三档颜色（ok 绿 / err 红 / info 灰）

§4底栏 SB

v1.2.0 新增底栏，替代原顶栏的「版本号」功能，并扩展实时状态提示。

ID选择器说明
SB-ver#ver版本号，DOMContentLoaded 时通过 huepick.getVersion() 从主进程 IPC 拉取（单一来源 package.json）
SB-text#status-text实时状态：就绪 / 共 N 张 / 已选中 M/N / 正在生成 (k/N) / 已生成 N 张

§5交互速查

场景操作结果
添加图片拖入窗口 / 单击 C1-02 / 点「选择文件夹」追加到列表，自动选中首张
单选单击列表项清空其他选中，仅选中当前
多选切换Ctrl+单击切换当前项选中状态
连选Shift+单击从锚点（上次单击）到当前项全选
连选叠加Ctrl+Shift+单击在现有选中基础上加入连续区间
全选Ctrl+A（列表聚焦时）选中全部
删除选中Delete / 点 C1-04删除所有选中项
取消选择Esc清空选中集
单删一项点列表项 ✕仅删除该项，不影响其他选中
改参数拖动 / 切换 C2-R1 任意控件350ms 防抖后自动刷新预览
正式生成点 C2-R1a「🚀 生成色卡」按当前参数对列表所有图批量生成到原图目录
复制色值点预览区下方色块HEX 复制到剪贴板
就绪 · 点击图鉴中的编号芯片查看说明
