§0编号规则与使用方法

编号是锁定位置的唯一标记：调整布局前先在图上找到目标编号，改完 HTML/CSS 后回来核对编号仍指向同一功能。点击图中任意编号芯片，页面底部会显示它的完整说明；表格行也会同步高亮。

W{1..9}
顶级窗口，按创建顺序编号
W1-{区域字母}
窗口内大区域（R1 顶栏 / C1 左栏 / C2 右栏 / E 浮层）
W1-{区域}-{NN}
区域内两位序号，定位到具体控件
铁律
编号不可改 · 不复用 · 删除跟随删除 · 新增顺序续编
R1 顶栏 C1 左栏（拖拽/列表） C2 右栏（参数/预览/日志） E 全局叠加层

§2W1-R1 顶栏 · 4 项

Electron BrowserWindow 创建时设置 icon（build/icon.ico，9 种尺寸打包）和 title（「HuePick — 拾色」）。顶栏版本号通过主进程 IPC 链路从 package.json 单一来源读取：main.js fs.readFileSync → ipcMain.handle('app-version') → preload getVersion() → renderer DOMContentLoaded 写入 #ver。

W1-R1-02品牌名 HuePickindex.html #ver 前兄弟 span；color: #E8E8E8；font-weight: 600
W1-R1-03版本号 v1.0.0index.html span#ver（初始硬编码占位 v0.5.0，启动后被 app.js 异步改写）；主进程 IPC 链路单一来源
W1-R1-04窗口标题Electron BrowserWindow.title = 'HuePick — 拾色'

§3W1-C1 左栏 · 拖拽区 + 文件列表

左侧固定宽 330px 面板。顶部虚线拖拽区（半透明 border）接受文件/文件夹拖入；拖拽事件同时监听 document（全局）和 #drop（视觉反馈）；双路径合并（dataTransfer.files + webkitGetAsEntry），Set 去重。下方文件列表是当前选中的主数据源。

编号控件说明
W1-C1-01拖拽区 .dropzonedocument.addEventListener('dragover'/'drop') 全局接文件；#drop 仅视觉提示（classList.add('dragover')）；双路径合并 Set 去重；onDrop → addFiles(paths) → 自动选中第一张 → 触发预览
W1-C1-02文件列表 ul#file-listli.item { padding: 6px 10px; border-radius: 6px }；选中项 background rgba(46,138,176,.2) + 左侧 2px accent 色条；✕ button.ghost → removeFile(path)

§4W1-C2 右栏 · 参数面板 + 生成 + 预览 + 日志

右侧宽 826px 自适应。从上到下依次：参数面板（2 行） → 生成按钮（主 accent 色） → 预览区（自适应高度） → 日志面板。**任何参数改动都会 350ms 防抖后自动刷新预览**（change + input 事件）。预览走 IPC generate-card 带 preview:true，落 %TEMP%\HuePick-preview\，不污染原图目录。

编号控件说明
W1-C2-02色数label「色数」两字 + input number min=3 max=12 default=6；改任何参数 350ms debounce 触发 previewDebounced()
W1-C2-03模板6 种：landscape 1920×1080（默认）/ portrait 1080×1920 / square 1080×1080 / compact 1200×800 / thumb 800×450 / palette 1200×240（无图纯色板）
W1-C2-04主题深色（#18181A，默认）/ 浅色（#F5F5F7）；画布背景色传入 canvas 渲染；文字颜色由 inkColor(bg) 自动反色
W1-C2-05裁切checkbox 选中后 cropper.cropBlackBars() 在 extractPalette 之前执行，避免电影上下黑边稀释主色
W1-C2-06格式影响 cardRenderer.toFile() format 参数；jpg → canvas.toFile(path, {format:'jpeg',quality:0.92})；png → format:'png'；主进程根据扩展名决定输出路径
W1-C2-07🚀 生成色卡按钮主 accent 色；payload.preview=false（默认）→ 输出到原图目录 + 冲突自动编号（色卡 → 色卡 (2) → 色卡 (3)）；payload.preview=true 时走预览链路落 %TEMP%\HuePick-preview\
W1-C2-08预览区 img#previewsrc = pathToUrl(r.outputPath) + '?t=' + Date.now() 绕开 Electron file:// 缓存；选中文件自动生成首张；参数变化 350ms debounce 自动刷新；输出路径始终为 temp 目录（preview:true）不污染原图目录
W1-C2-09日志 ul#logli.info 前景色 var(--muted)；li.err 前景色 #E07A45；每次 generateCard 返回后 li 追加 + scrollTop=scrollHeight
W1-E-01空状态占位未选中文件时显示；icon + 提示文字；选中文件后隐藏由 img#preview 取代

§5参数详解速查

模板 → TEMPLATE_SIZES
landscape 1920×1080（默认） · portrait 1080×1920 · square 1080×1080 · compact 1200×800 · thumb 800×450 · palette 1200×240
主色提取算法
extractPalette() 基于 k-means 聚类（quantize 色彩量化）；cropBars=true 时先 cropBlackBars() 裁掉电影上下黑边；主色数量 3~12（默认 6）
渲染链路
cardRenderer.generateCard(sourcePath, options) → Canvas(cardWidth, cardHeight) → layout 分支（横/竖/自动网格/palette）→ canvas.toFile(outputPath, {format, quality:0.92})
字体自适应
scale = clamp(cardWidth/1920, 0.5, 1)；所有字号 padding gap 等按比例缩放；clamp Math.max(...) 保证小画布仍可读
打包配置
electron-builder win nsis；"icon": "build/icon.ico"；build/**/* 进 asar；preload.js 中 path.join(__dirname, '..', 'build', 'icon.ico') 打包后路径仍有效
