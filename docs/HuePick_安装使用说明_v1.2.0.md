# HuePick v1.2.0 安装使用说明

> 配套安装包：`HuePick-Setup-1.0.0.exe`（约 94 MB）
> 适用对象：所有用户；从 v0.6.0 升级的用户请直接运行新安装包覆盖即可。

---

## 一、版本与系统要求

| 项目 | 要求 |
|------|------|
| 版本 | v1.2.0 |
| 操作系统 | Windows 10 / Windows 11（64 位） |
| 磁盘空间 | 安装约 94 MB |
| **预装环境** | **无**——Node.js、Electron 运行时、Skia 图形库已全部打包进安装包，换电脑即装即用 |

---

## 二、安装步骤

1. 双击 `HuePick-Setup-1.0.0.exe` 启动安装向导。
2. 欢迎页 → 「下一步」。
3. **选择安装位置**（默认 `C:\Users\<你的用户名>\AppData\Local\Programs\HuePick`），建议保持默认；也可改到其他盘。
4. **附加任务**：勾选「创建桌面快捷方式」（可选）→ 「下一步」。
5. 点「安装」，等待进度条完成。
6. 安装完成 → 勾选「运行 HuePick」→ 「完成」。

> **提示**：本安装包**无需管理员权限**。若 Windows SmartScreen 弹出「已保护你的电脑」，点「更多信息」→「仍要运行」即可。

> **便携版**：也可直接使用 `dist\win-unpacked\HuePick.exe`，双击即用，无需安装。

---

## 三、启动与卸载

- **启动**：开始菜单 →「HuePick」，或双击桌面快捷方式，或双击安装目录下的 `HuePick.exe`。
- **卸载**：开始菜单 →「HuePick」→「卸载 HuePick」；也可在「设置 → 应用 → 已安装的应用」中找到「HuePick」卸载。

## 五、快速上手（30 秒出第一张色卡）

1. **拖图**：把一张或多张图片拖到左栏虚线框内（或点击虚线框选择文件）。
2. **看图**：选一张图片 → 参数面板自动展开 → 预览区实时显示色卡。
3. **调参**：拖动色数滑块、切换模板/主题 —— 每次改动 350ms 后自动刷新预览。
4. **生成**：点右下角「🚀 生成色卡」按钮，色卡输出到原图所在目录，文件名 `原名_色卡.jpg`。

## 六、模板图鉴

HuePick v1.2.0 提供 **6 种内置模板**，覆盖从大屏展示到截图标注的全部场景：

### 6.1 横版（默认）— 1920×1080

大图占 66% 画布，底部色块区自适应网格，适合做海报、桌面壁纸、作品集展示。

![横版 1920×1080](guide_assets/card_landscape.jpg)

### 6.2 竖版 — 1080×1920

每行排布色块 + 占比 + HEX，适合手机屏、短视频封面。

![竖版 1080×1920](guide_assets/card_portrait.jpg)

### 6.3 方版 — 1080×1080

正方形画布，自动网格换行。**支持高色数自动折行**，不会挤成一条。

![方版 1080×1080 · 6 色](guide_assets/card_square_c6.jpg)

![方版 1080×1080 · 10 色（自动换行）](guide_assets/card_square_c10.jpg)

### 6.4 紧凑 — 1200×800

缩略图占比缩小到 45%，色块区更密。适合社交媒体、博客配图。

![紧凑 1200×800](guide_assets/card_compact.jpg)

### 6.5 缩略 — 800×450

最小截图模板，字体/间距自动缩至 800 宽级别。适合嵌入文档、Markdown。

![缩略 800×450](guide_assets/card_thumb.jpg)

### 6.6 色板 — 1200×240（无图纯色块）

**完全不显示原图**，整条画布全部给色块信息。色块内置左上角占比 + 右下角 HEX，纯信息展示，适合快速贴到幻灯片/设计稿里。

![色板 1200×240](guide_assets/card_palette.jpg)

## 七、参数详解

| 参数 | 默认 | 可选值 | 说明 |
|------|------|--------|------|
| **色数** | 6 | 3 ~ 12 | 从原图提取几个主色，色数越多越精细 |
| **模板** | 横版 | 横版 / 竖版 / 方版 / 紧凑 / 缩略 / 色板 | 见第六节图鉴 |
| **主题** | 深色 | 深色 / 浅色 | 画布背景色 + 文字颜色自动适配 |
| **裁切** | ✅ 开启 | 开关 | 开启后自动裁除电影上下黑边，让主色提取更准 |
| **格式** | JPG | JPG（体积小）/ PNG（无损） | JPG 比 PNG 小 60~70%，PNG 保留色彩精度 |

> 所有参数改动都会**自动刷新预览**（350ms 防抖），无需手动刷新。

## 九、输出命名规则

生成色卡时，文件名自动追加 `_色卡` 后缀：

| 原图 | 第一次生成 | 冲突时自动编号 |
|------|-----------|----------------|
| `森林日落.jpg` | `森林日落_色卡.jpg` | `森林日落_色卡 (2).jpg` → `(3)` … |

- 预览图**不会**写到原图目录（落到系统临时目录，自动覆盖），不会污染你的文件夹。
- 只有点「🚀 生成色卡」按钮才会正式落盘。
- 不会覆盖已存在的色卡文件，自动顺着编号走。

## 十、常见问题

**Q1：拖完图没反应？**
左栏会显示文件列表，列表选中后自动生成预览。如果列表是空的，说明拖拽没有触发 —— 确认图片是常见格式（JPG / PNG / WebP / BMP）。

**Q2：预览和生成的结果不一样？**
预览和正式生成走的是同一条渲染链路，结果应该一致。唯一区别是：预览落临时目录，正式生成落原图目录。

**Q3：想批量处理多张图？**
一次拖多张 → 点「🚀 生成色卡」按钮 → HuePick 会按当前参数**逐张生成**，全部输出到各自原图目录。日志面板会显示进度。

**Q4：生成的色卡里某些色块看起来太暗/太亮？**
那是原图里的真实颜色。HuePick 的主色提取基于 K-means 聚类，不带任何主观滤镜。如果想调整视觉效果，建议后期在 PS/LR 里对原图先做统一调色再提取。

**Q5：安装时提示「已保护你的电脑」？**
SmartScreen 对未签名程序的常规提示，点「更多信息」→「仍要运行」即可。
